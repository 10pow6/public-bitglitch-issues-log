# BitGlitch — Public Issue Tracker

Welcome! This is the **public bug & feedback tracker** for [BitGlitch](https://bitglitch.tp.land) — the creature‑collection game where you summon *Glitches* from your TelePortals short URLs.

This repository contains **no game source code**. It exists so players can report bugs, request features, and track what we're working on — all in the open.

---

## 🐛 Found a bug? Have an idea?

[**→ Open a new issue**](https://github.com/10pow6/public-bitglitch-issues-log/issues/new/choose)

Pick the right template and fill in as much as you can:

| Template | Use it when… |
|----------|--------------|
| 🐛 **Bug Report** | Something is broken, errors out, or behaves differently than expected. |
| ✨ **Feature Request** | You have an idea for a new Glitch, mechanic, or quality‑of‑life improvement. |

Before opening one, please [**search existing issues**](https://github.com/10pow6/public-bitglitch-issues-log/issues?q=is%3Aissue) — if your bug or idea already exists, add a 👍 or a comment instead of opening a duplicate. It helps us prioritize.

## 🔒 Security issues

**Do not** open a public issue for security vulnerabilities. [**Report it privately →**](https://github.com/10pow6/public-bitglitch-issues-log/security/advisories/new) (see [**SECURITY.md**](SECURITY.md) for what to include and what's out of scope).

## 💬 Want to chat instead?

Join the community on **Discord** (linked in‑game and on the [BitGlitch site](https://bitglitch.tp.land)) for live discussion, help, and announcements. GitHub issues are best for things we need to track and fix; Discord is best for questions and conversation.

---

## How we handle issues

- We triage new issues and apply labels (e.g. `bug`, `enhancement`, `needs-info`, `confirmed`, `wontfix`).
- If we need more detail we'll add `needs-info` and comment — please reply, or we may close the issue after a while.
- Fixed issues are closed with a note. Shipped features are closed when they go live.
- This is the canonical place to see **what's reported and what's planned**.

## Tips for a great report

1. **One issue per report.** Separate bugs into separate issues.
2. **Be specific.** "Summon button does nothing" beats "it's broken."
3. **Include steps** to reproduce, what you expected, and what actually happened.
4. **Add screenshots or a short clip** when the bug is visual.
5. **Tell us your setup** — browser, device, and (if relevant) your in‑game handle.

Thanks for helping make BitGlitch better! 🎮
